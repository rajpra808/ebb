# Safety and security

Ebb looks at people's disks, so a mistake can cost someone their work. If Ebb ever suggested, moved or read something it
shouldn't have, please report it privately through
[GitHub's security advisories](https://github.com/rajpra808/ebb/security/advisories/new) rather than in a public issue.

Helpful details: the path involved (with private parts removed), the category or rule, the output of `ebbctl --version`, and
what made the item unsafe.

Reports are answered within a few days, and fixes come with a test in the never-touch suite so the same thing can't come back.
